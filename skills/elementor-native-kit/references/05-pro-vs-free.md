# 05 — Elementor Free vs Pro capability matrix

Method: Elementor Free is public, so "Free" means *the widget class exists in
`elementor/elementor@v3.35.9`* (`includes/widgets/*.php`). Elementor **Pro is closed
source**, so no Pro control id in this file is asserted as verified — Pro rows describe
behaviour and fallbacks, never unverified control names.

Regenerate the Free column mechanically:

```bash
python3 skills/elementor-native-kit/scripts/extract_controls.py --source <checkout> --tag v3.35.9
cat skills/elementor-native-kit/references/_generated/widget-taxonomy.md
```

## 2. Non-widget capabilities

| Capability | Tier | Evidence / reason | Kit position |
| --- | --- | --- | --- |
| Theme Builder **assignment** (header, footer, single, archive, search, 404, popup conditions) | **Pro** | Theme Builder is an Elementor Pro module; the free plugin has no conditions UI | Templates ship as documents; the *assignment* is a documented manual step (`docs/05-theme-builder.md`) |
| **Exit-intent popup** | **Pro** | Popups are Pro (`Popup` document type + triggers) | `templates/popups/aurora-lead-magnet.json` ships the layout; trigger is set by hand |
| **Sticky** header behaviour | **Pro** | `Controls_Manager::add_motion_effects_promotion_control()` renders a `sticky_pro` promotion lock on Free (`includes/managers/controls.php`, the `sticky_pro` control) | Header ships without sticky keys; documented as a manual Pro step. **No `sticky*` key is emitted into any template.** |
| **Scrolling / mouse / transform Motion Effects** | **Pro** | same promotion control (`scrolling_effects_pro`, `mouse_effects_pro`) | Never emitted (`07-motion-effects.md`) |
| **Entrance animation** (`animation`, `_animation`) | **Free** | `common-base.php:L838`, `container.php` motion section | Used throughout — this is the only animation mechanism |
| **Responsive "Hide On" visibility** | **Free** | `includes/base/element-base.php:L1383` `add_hidden_device_controls()`, ids `hide_<device>`, `return_value: hidden-<device>`, `prefix_class elementor-`; called from `container.php:L1906` | Used for the header button group (`hide_tablet`/`hide_mobile`) |
| **Flexbox Containers** | **Free**, but an *experiment* | `elementor → Settings → Features → Flexbox Container` | Required; the kit is containers-only |
| **Custom Fonts** (needed for Arad) | **Pro** | `Elementor → Custom Fonts` is a Pro feature | Documented in the kit's `docs/04-rtl-persian-setup.md`; without it, substitute a Google-hosted Persian family |
| **Forms → Actions After Submit** (Mailchimp, webhook…) | **Pro** | Pro form actions | Documented in `docs/05-theme-builder.md` |
| **Global Colors / Fonts, Theme Style, Kit document** | **Free** | `core/kits/documents/tabs/*` in the free source | The whole design system |
| **Page settings** (`hide_title`, `template`) | **Free** | page settings, emitted as `page_settings` in the JSON | Page templates do not carry `hide_title`; it is a documented per-page step |

## 3. Rules this matrix creates

1. A Pro widget may appear in a template **only** if its Free behaviour is documented above
   and degrades to an empty (not broken) box.
2. No `sticky*`, `motion_fx_*` or other unverifiable Pro control id is ever written into a
   template JSON — see the UNVERIFIED headings in `01`, `07` and this file.
3. Anything a non-coder must click in the Elementor panel (assign a condition, set a popup
   trigger, turn on sticky) is a documented manual step in the kit's `docs/`, not JSON.

## UNVERIFIED — do not emit

* Every Pro widget's control ids (`form_*`, `posts_*`, `nav_menu_*`, `breadcrumbs_*`,
  `post_*`, `theme_*`, `archive_*`). The kit *does* emit structural keys for some of these
  (`_skin`, `posts_per_page`, `pagination_type`, plus `cards_*`-prefixed style keys on the
  archive widget). Those keys came from an earlier session and **could not be re-verified in
  this phase** because Elementor Pro is closed source. They are recorded as a
  re-verification task in `HANDOFF-P0.md`; the field names are stored verbatim in the
  templates, so a wrong name is inert rather than fatal, and an editor can always set the
  value again in the panel.
* Elementor Pro's Loop Grid / Loop Item template JSON shape (`loop-grid`), which is
  documented in the kit's `docs/05-theme-builder.md` as a manual alternative only.
