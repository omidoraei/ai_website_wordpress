# Claim ledger

Every factual claim this project has made about Elementor, about counts, or about its own
verification lives here. A claim is not "settled" until its status is VERIFIED with a command
and an artifact behind it.

**Statuses:** `VERIFIED` (command + artifact agree) · `RETRACTED` (proven wrong; propagate the
fix) · `UNVERIFIED` (never proven either way) · `SUPERSEDED` (replaced by a defined metric).

## Retraction protocol

A retraction is not complete until **every public surface** is updated in the **same phase**:
PR body, README, CHANGELOG, `docs/**`, commit messages and run titles. The machine-readable
list of phrases that must no longer appear is the block below; the CI step *Retraction guard*
reads it, scans the public surfaces, prints how many files it examined, and exits 1 on any hit.

<!-- RETRACTED-PHRASES (one per line; matched case-insensitively) -->
```retracted-phrases
dual-write
write both the 3.x
missing from v3.35.9
18 colours
18 fonts
18 global colors
18 global colours
40 templates
artifact digest proves
sha256 proves determinism
```
Surfaces excluded from the guard (they are the ledger itself or recorded evidence):
`docs/CLAIMS.md`, `HANDOFF-*.md`, `docs/_generated/**`.

## How to add a row

1. Claim text verbatim as it appeared, plus where it first appeared.
2. Status after checking, with the exact command and artifact path in `evidence`.
3. List every file that repeats the claim in `propagated-to`; if the claim is RETRACTED, add a
   line to the `retracted-phrases` block so the CI guard fails until every surface is fixed.
4. Date in ISO form.
